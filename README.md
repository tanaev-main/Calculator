# Программа калькулятор


Программа поддерживает следующие опции
    - `add`        | `складывает два числа и возвращает результат `
    - `subtract`   | `вычетает два числа и возвращает результат  `
    - `multiply`.  | `умножает два числа и возвращает результат`

В папке проекта выполните :

    python3 calculator.py

# Пример 

Вызовы функций:

```python
print("Сложение: 2 + 3 =", add(2, 3))
print("Вычитание: 7 - 4 =", subtract(7, 4))
print("Умножение: 2 * 4 =", multiply(2, 4))
```

Вывод:

```text
Сложение: 2 + 3 = 5
Вычитание: 7 - 4 = 3
Умножение: 2 * 4 = 8
```
