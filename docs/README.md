# Документация калькулятора

## Описание программы

Программа выполняет простые действия с двумя числами.
Поддерживает сложение, вычитание и умножение.

Числа задаются в коде. Каждая функция принимает два числа
и возвращает результат.

## Функция add

Складывает два числа и возвращает результат.

- `a` — первое число.
- `b` — второе число.

Пример вызова:

```python
add(2, 3)
```

Результат:

```text
5
```

## Функция subtract

Вычитает второе число из первого и возвращает результат.

- `a` — первое число.
- `b` — второе число.

Пример вызова:

```python
subtract(7, 4)
```

Результат:

```text
3
```

## Функция multiply

Умножает два числа и возвращает результат.

- `a` — первое число.
- `b` — второе число.

Пример вызова:

```python
multiply(2, 4)
```

Результат:

```text
8
```
